# E 视力表

一个基于浏览器的可调测距 E 视力表，适合在电脑或平板上进行快速自测与教学演示。

## 项目简介

本项目是一个单页 HTML 应用，用来模拟常见的 `E` 字视力检测表。用户可在页面中设置测试距离、视力等级，以及纸质/电子模式主题，然后按键盘方向键回答展示的 `E` 字朝向。

它适合：

- 个人自测视力相关认知与方向识别能力
- 眼科/视觉相关教学演示
- 轻量化前端练习与单文件网页 demo

## 功能特点

- 可配置测试距离（如 0.4m、0.5m、1m、2.5m、3m、5m、6m）
- 可选择不同视力等级
- 60 秒计时挑战
- 方向键回答：`↑ ↓ ← →`
- 空格键暂停/继续
- 自动记录测试历史
- 纸质模式 / 电子模式切换
- 纯前端实现，无需后端环境

## 运行方式

1. 下载或克隆本仓库

## 使用说明

1. 打开页面后，先进行屏幕校准
2. 使用尺子对照页面中的黑色标尺，调整浏览器缩放，使其长度等于 5cm
3. 选择测试距离和目标视力等级
4. 点击“开始 60 秒挑战”
5. 观察屏幕中的 `E` 字方向，并使用方向键进行判断
6. 测试结束后查看结果和历史记录

## 注意事项

- 本项目仅用于教学、娱乐或自测辅助，不可替代专业眼科检查
- 测试结果仅供参考，环境光照、屏幕分辨率、浏览器缩放等因素可能影响结果
